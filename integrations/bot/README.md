# Revolution 消息入口通用接口

`core.mjs` 定义飞书与微信连接器提交给 Revolution 的统一事件字段，并在进入 DSH 任务队列前检查账号绑定、用户授权、群聊触发条件和事件去重。每条事件必须映射到一个 `revolutionUserId + workspaceId`，不会使用全局共享会话。队列提交失败时释放去重占位，允许平台重试。

这是平台无关的核心接口，尚未连接真实飞书或微信回调，也没有安装全局机器人。平台适配器必须在调用 `routeBotEvent` 前验证平台签名或使用官方可信长连接；`resolveBinding`、`canAccess`、原子持久化 `dedupe` 与 `enqueue` 由产品运行时提供。不能把测试中使用的内存集合当成多用户生产存储。

当前只提供接入边界和测试。个人飞书开放平台应用权限尚待确认；微信官方入口尚未选定。真实账号、授权、回复发送和 DSH 会话桥接会在这两个条件满足后实现。
