# Revolution 飞书研发机器人：开发目标与验收

更新：2026-10-25。手机飞书私聊到本机 Revolution、再到飞书回复的基础闭环已经通过；下一阶段是完善创建、模型、停止等人工验收和交互体验。

## 使用目标

1. Revolution 保持运行且电脑在线时，飞书机器人保持事件长连接；断线自动重连。电脑休眠、关机或网络中断时不承诺实时执行。
2. 私聊中能列出、选择 Revolution 项目（DSH 工作区）和项目内的顶层 session。切换项目即清空会话选择，防止消息误投。
3. 私聊中能创建新的本机项目文件夹，创建并选择项目中的任务 session。普通消息提交到所选 session，由 DSH 使用该 session 的工具和权限执行。
4. 能从飞书取消所选 session 的当前执行，查看最近一次文字回复；发起的每条消息完成后由机器人自动回传文字结果。取消保留 DSH 原有的排队消息，这一点需在产品文案中明确。
5. 能列出该 Revolution 实例可用的模型，按提供商和模型 ID 为所选 session 选择模型；模型是否可用和凭证是否齐备以 DSH 实时目录与校验为准。
6. 飞书私聊仅绑定本机已授权的同一飞书用户和一个 chat ID；未知发送者、未知项目、未知 session 不可触发执行。消息 ID 去重，凭证不写入仓库或机器人回复。

## 当前命令入口

| 命令 | 行为 |
| --- | --- |
| `/当前` | 查看当前项目和会话 |
| `/项目`、`/项目 <ID>` | 列出和选择项目 |
| `/会话`、`/会话 <ID>` | 列出和选择当前项目的会话 |
| `/新建项目 <名称>` | 创建本机项目文件夹并选中 |
| `/新建任务 <名称>` | 创建 DSH session 并选中；下一条普通消息开始执行 |
| `/结果` | 查看所选 session 最近的文字回复 |
| `/停止` | 取消所选 session 的当前执行 |
| `/模型`、`/模型 <提供商>/<模型ID>` | 列出和选择 session 模型 |

聊天输入框上方的可点击项目、会话和模型选择器尚未实现；当前命令入口先用于验证真实链路。后续可通过飞书交互卡片或应用菜单提供同样操作，但须核对当前平台的回调、权限和客户端支持。

## 真实闭环验收

1. 使用新的 Revolution 构建启动，在设置中确认飞书连接和机器人已启用。事件消费者持续运行；启动时凭证暂不可用或连接断开后能自动恢复。
2. 用授权的手机飞书账号私聊机器人发 `/当前`、`/项目`，收到列表。发 `/新建项目 验收项目`、`/新建任务 验收任务`，桌面端能看到对应工作区和 session。
3. 发 `/模型`，选择一个已配置模型；发送一个明确的测试问题，桌面 session 出现同一用户消息，飞书收到该 session 的真实文字回答。`/结果` 能再次读到回复。
4. 让模型运行一个可观察的长任务，发 `/停止`，桌面当前执行停止；核对已排队消息的处理符合 DSH 原生语义。
5. 重发同一个平台消息 ID 不产生第二次任务；换一个飞书账号或聊天不能操作绑定会话。重启 Revolution 后绑定状态保持，断开飞书或禁用机器人后不再接收任务。
6. 记录失败时的非密钥错误、发生时刻和平台消息 ID；逐项核查事件订阅、机器人可用范围、消息权限、DSH 模型凭证与本机网络。

## 当前验证与剩余工作

本机已经验证官方飞书 CLI 的用户和机器人身份均可用、事件订阅和权限预检通过、WebSocket 可连接。自动化测试覆盖消息规范化、去重、私聊绑定、项目和会话切换、创建、停止、模型选择、结果读取以及 DSH 回复桥接。`~/Applications/Revolution Preview.app` 已安装 `0.1.4-preview.4`：启动前要求首次绑定的飞书个人身份，运行时显示机器人连接状态。2026-10-25 已由用户在真实飞书私聊确认 `/当前`、`/项目`、`/会话` 均能收到回复；创建、模型切换、真实模型回答和停止流程仍需继续人工验收。

下一步实现输入框上方的可点击选择器、运行中进度与长回复分页、任务历史。多人账号隔离和公共应用发行保留为有基础设施后再启动的阶段；微信连接、团队知识库和跨设备离线执行另列后续阶段。

## 每人安装、共用机器人方案

R4 开发候选增加可部署的单组织中转服务。飞书机器人只在服务端保持一条长连接；每个桌面客户端通过飞书 OAuth 登录，回填一次性确认码后获取本机设备会话，并以 HTTPS 长轮询收取属于自己 `open_id` 的私聊消息。应用密钥不进入安装包。详细部署步骤、限制和本地测试见 `services/revolution-relay/README.md`。目前尚无服务器、域名和正式飞书应用配置，未进行真实多人及跨组织验收，不能称为已对所有飞书用户开放。

目标用户也可能使用不同组织的飞书个人账号。正式公开分发应申请飞书商店应用，使用服务端事件回调、按租户管理应用凭据，并验证个人版用户的安装与授权流程。当前自建应用长连接只用于单组织试点；不能将其 App Secret 打进每位用户的安装包，也不能让每台电脑用同一 App ID 各建长连接。
