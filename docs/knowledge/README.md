# Revolution 个人知识库

建议按顺序学习，每篇都包含可以在本仓库验证的练习。

1. [CI/CD 从提交到安装包](01-ci-cd.md)：理解并运行已实现的流水线。
2. [Agent、DSH 与 Workflow](02-agents-and-dsh.md)：理解系统边界，而非把插件当成一个模型。
3. [Jev 自动路由探索](03-jev-routing.md)：不输入“使用 workflow”也能选择任务组织方式。
4. [Figma 交互与复用说明](04-figma.md)：页面、组件、点击行为与实现边界。
5. [本轮验收记录](05-validation.md)：真实运行链接、下载位置与尚未验证的边界。

使用方法：读一篇，做一次练习，记录自己的结果、失败原因和下一次要验证的假设。不要把 API Key、会话日志或私人文件上传到这个公开仓库。
