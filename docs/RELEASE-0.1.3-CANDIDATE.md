# Revolution 0.1.3 预览候选验收

版本目标：个人知识库自动召回、飞书私聊与 Revolution 工作区/会话切换。DeepSeek Harness 固定为 `0.2.1-rc.2`。

## 已自动验证

- 知识库同步、个人插件、机器人事件路由及 CLI 传输测试。
- Electron 临时 profile：侧栏、知识检索、机器人默认关闭和请求保护。
- macOS 本地预览包：独立运行时、包内插件、Node/飞书 CLI 签名。
- 远端三平台构建与校验以对应 GitHub Actions 结果为准，不能用本地 macOS 结果代替。

## 人工发放门槛

1. **手机飞书实测**：在已授权的个人账号私聊机器人，发送 `/项目`、切换工作区、发送 `/会话`、切换会话、提出一个普通问题，核对它进入选定的 Revolution 会话并将真实回答发回飞书。重启 Revolution 后复测绑定和去重；断线期间确认失败状态可见。
2. **长期记忆实测**：保存一条可识别的个人知识，在新会话提问，核对自动召回的内容和来源；随后修改或删除原文，确认旧内容不再被召回。检查误召回与响应时间。
3. **安装和回归**：从本次构建产物在独立环境验证下载安装、首次模型配置、普通对话、历史恢复、Workflow、知识面板及退出重启。macOS 仅临时签名且未公证；Windows 未签名。
4. **发行范围**：当前只支持本机单用户与其个人飞书私聊。团队知识权限、群聊、微信、电脑离线托管均不在 0.1.3 候选版承诺内。

候选版先保留在构建产物或 Draft Release 中。上述人工门槛完成并记录结果后，再公开发布或向测试者发放。此前版本不会自动升级。
