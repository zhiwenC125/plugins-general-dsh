# Revolution 知识库与飞书连接插件

已接入 Revolution 桌面安装包：侧栏「知识库」及设置中的「飞书与知识库」。当前版本面向本机单用户运行，要求 DSH 监听环回地址。

## 用户使用

1. 打开「知识库」，点击「连接飞书」。首次可通过飞书官方设备流程创建自己的个人应用，然后进行用户授权；也可在「使用已有飞书应用」填写自己的 App ID / App Secret。凭据由固定版本的官方 `@larksuite/cli` 管理，不进入浏览器响应或知识仓库。
2. 在页面显示的飞书链接中确认登录与授权。需同步写入时点击「授权文档同步写入」。凭证刷新由官方 CLI 在 API 请求时处理；撤销、刷新凭证过期或新增权限后需重新授权。租户管理员限制仍然适用。
3. 新用户默认得到独立的空知识库，创建自己的文章即可使用。也可将已克隆的知识仓库（包含 `knowledge/catalog.json`）设为 Markdown 原文目录。不会自动复制开发者的账号、空间 ID 或私人内容。
4. 分别设置 Obsidian 库完整路径、普通文档文件夹链接、Wiki 空间设置页链接。三个副本保存同一套完整文章，可预览同步、写入和拉回修改。远端和本地同时修改会报冲突。
5. 旧命令行用户在保存原来的路径和目标后，展开「从旧版命令行迁移」。迁移会实时读回旧飞书文档并验证哈希，之后复用已有文档。
6. 可直接在 Revolution 聊天中检索知识、读取飞书文档链接或生成知识文章草稿。草稿在面板中确认保存，之后手动同步。新文章不会自动推送 GitHub。
7. 「飞书中的 Revolution」可启用本机个人机器人。当前只接受已授权飞书账号的私聊。飞书中使用 `/项目` 与 `/会话` 列表并按 ID 切换；项目第一版对应 DSH 工作区。选定会话后，普通消息进入该会话并由机器人回复。电脑需要保持在线；上线前仍需在真实手机飞书完成端到端验收。

飞书授权用于知识数据访问，与原来的 DeepSeek/微信模型账号登录分别管理。飞书登录本身不提供模型服务或额度。

## 检索与 RAG

本版提供中英文文本分块、关键词召回和来源行号。每轮用户输入的第一个模型步骤会自动检索本地知识副本，并注入最多三个带来源的片段；模型仍可调用 `revolution_knowledge_search` 深入检索。这构成检索增强生成的基础流程，但不等于模型会自动记住所有聊天内容。长期事实需经用户确认保存为文章；目前没有后台自动提炼或自动写入记忆。未接入向量数据库、Embedding 模型、语义重排或后台全量抓取。

当前知识库属于本机个人用户，所有会话共享同一套本地文章。团队知识需要另加工作区/项目范围、成员身份、资源 ACL、共享源及权限变更后的索引失效，不能直接把当前个人副本开放给多人。

- `revolution_knowledge_search`：检索用户选择的本地知识副本，返回片段及来源行号。
- `revolution_knowledge_read`：按 ID 读取原文和哈希。
- `revolution_feishu_read`：按 docx/Wiki 链接实时调用飞书权限检查并读取纯文本。
- `revolution_knowledge_propose`：生成待确认草稿，不直接写入原文或远端。

同步仍使用现有纯文本块 Markdown 往返规则。飞书富文本原文可按链接读取纯文本；图片、附件、评论和复杂表格的完整往返不在本版支持范围。已明确拉回本地的文件是用户持有的本地副本；退出飞书不等于删除这些本地文件。实时飞书读取在退出后不可用。

## 开发与验证

```sh
npm run build:knowledge
npm run test:knowledge-app
npm run setup:revolution
npm run start:revolution
```

`engine/` 由 `knowledge/core.mjs` 和 `knowledge/feishu.mjs` 构建生成，共用同步实现。`lib/client.js` 为浏览器构建产物。桌面构建安装固定的官方 CLI 1.0.98，并由上游安装脚本校验下载的本机平台二进制。

桌面安装依赖后，可用 Electron 执行 `scripts/smoke-knowledge-electron.cjs` 验证真实 DSH 启动、已登录 HTTP 请求、创建/检索文章、侧栏页面与 CSRF 拒绝。该测试使用临时数据目录，不执行真实飞书写入，也不代表 OAuth 已通过真实用户确认。

所有接口复用 DSH 的 Host/Origin 与会话认证检查；写请求额外要求 JSON 和自定义请求头。模型工具没有登录、修改账号、修改路径和执行任意 CLI 的能力。飞书 CLI 进程使用独立的 Revolution 配置目录，业务正文经 stdin 传递，原始授权输出不写日志。

## 尚需真实账号验收的项目

本地集成测试不替代飞书服务端验收。用户需首次完成授权，随后检查普通文档和 Wiki 读取、写入、令牌续期与撤销。机器人接入已实现本机个人私聊路径，但尚未收到真实手机消息做端到端验收；群聊、托管服务和跨租户公共应用发行不属于当前交付。
